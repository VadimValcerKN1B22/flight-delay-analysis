# Прогнозування затримок вильоту авіарейсів у США

* **Автор:** Вальцер Вадим
* **Група:** KN1-M26
* **Дисципліна:** Аналіз великих наборів даних

## 1. Питання дослідження
Чи можна передбачити затримку вильоту рейсу понад 15 хвилин за даними про авіаперевізника, аеропорт відправлення, запланований час вильоту та дистанцію польоту?

## 2. Дані
* **Назва:** [2015 Flight Delays and Cancellations](https://www.kaggle.com/datasets/usdot/flight-delays) (U.S. Department of Transportation)
* **Обсяг:** 5 819 079 рядків, 31 стовпець (~570 МБ CSV). Після фільтрації скасованих рейсів — 5 714 008 рядків.
* **Формат оптимізації:** Parquet (стиснення з 565 МБ до 30.9 МБ).

## 3. Як запустити проєкт
1. Встановити залежності:
```bash
pip install -r requirements.txt
```
2. Завантажити датасет `flights.csv` з Kaggle та покласти його в корінь проєкту (або поруч із папкою notebooks).
3. Послідовно виконати блокноти в папці `notebooks/`:
   * `01_data.ipynb` — завантаження, очищення даних, створення таргета `is_delayed`, оптимізація типів та конвертація в Parquet.
   * `02_eda.ipynb` — розвідувальний аналіз даних та побудова графіків у папку `report/figures/`.
   * `03_models.ipynb` — розбиття на train/test (80/20), навчання Baseline, Logistic Regression та LightGBM, розрахунок метрик.

## 4. Головні результати
1. Оптимізація форматів скоротила розмір даних у 18 разів (з 565 МБ до 30.9 МБ), а час читання через Polars скоротився до 0.23 с (у ~70 разів швидше за початковий CSV).
2. Дисбаланс класів: 82.3% рейсів вилітають вчасно, 17.7% мають суттєву затримку (> 15 хв).
3. Найнижчий ризик затримки спостерігається вранці (5:00–6:00, < 6%), тоді як увечері (18:00–20:00) частка затримок зростає майже до 28%.
4. Модель LightGBM показала результат ROC-AUC = 0.6916 на 1.14 млн тестових спостережень, суттєво перевершивши як Baseline (0.5000), так і лінійну регресію (0.6366) за 22 секунди навчання.
